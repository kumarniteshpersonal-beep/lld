## Requirements

- The vending machine should support multiple products with different prices and quantities.
- The machine should allow customers to view all available products.
- The machine should allow customers to select a product.
- The machine should accept coins of different denominations.
- The machine should allow money to be inserted in multiple steps.
- The machine should keep track of the total amount inserted for the current transaction.
- The machine should dispense the selected product, appropriate change.
- The machine should allow customers to cancel the transaction and receive a full refund before dispensing.
- The machine should maintain an inventory of products and update quantities after each purchase.
- The machine should maintain an inventory of coins and notes for accepting payments and returning change.
- The machine should fail the transaction if exact change cannot be returned.
- The machine should provide an interface for adding new products and restocking existing products.
- The machine should provide an interface for collecting the accumulated cash from the machine.
- The machine should handle insufficient funds, out-of-stock products gracefully.
- The machine should support multiple concurrent transactions while ensuring data consistency.
- The machine should ensure thread-safe updates to product inventory and cash inventory.
- The machine should prevent cash collection or product restocking from interfering with ongoing customer transactions.
